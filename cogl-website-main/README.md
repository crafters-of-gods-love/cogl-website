# Crafters of God's Love Website

Official website source for the Crafters of God's Love Minecraft community.

## Main files
- `index.html` — site content and structure
- `styles.css` — visual design and responsive styling
- `script.js` — interactive behavior
- `assets/` — images and other static assets
- `netlify.toml` — Netlify publishing configuration

## Local editing
Open `index.html` in a browser for a basic preview. For the full site, make sure all referenced files inside `assets/` are present.

## GitHub collaboration
Keep this repository private. Add approved staff as GitHub collaborators rather than sharing passwords.

Suggested workflow:
1. Pull the latest version before editing.
2. Make changes.
3. Commit with a short description.
4. Push to GitHub.
5. Netlify automatically deploys the new version from the connected repository.

## Netlify
This is a static site. The included `netlify.toml` publishes the repository root directly, so no build command is required.

## Privacy
Do not commit account passwords, API keys, private email addresses, home addresses, server control-panel credentials, or other sensitive information.
